# 백일오 · 다이스와 상태창 안내 (261120)

## 1. 다이스 설정

프롬프트 탭에서 '다이스 사용'을 켜고 아래 세 개를 추가한다. 이름은 프롬프트의 `{{dice:이름}}`과 철자가 정확히 같아야 한다.

| 이름 | 표기법 | 쓰는 때 |
|---|---|---|
| action | 1d20 | {{user}}가 위험하거나 결과가 불확실한 행동을 한 턴 |
| clock | 1d6 | `/다음날` 턴 |
| mood | 1d6 | 하루가 시작되는 장면(첫날 제외) |

**action 규칙 칸**
```
쉬움 7, 보통 11, 어려움 15 이상이면 성공. 기준보다 1~5 낮으면 아슬아슬(성공하되 대가), 6 이상 낮으면 실패. 20은 무조건 대성공, 1은 무조건 실패.
```

**clock 규칙 칸**
```
1-2: 결계의 균열 1칸 / 3-4: 차기 지휘관 다툼 1칸 / 5-6: 백일오의 사고 1칸. /다음날 턴에만 쓴다.
```

**mood 규칙 칸**
```
1: 심통이 나 있다 / 2-5: 평소와 같다 / 6: 이상하게 들러붙는다. 하루가 시작되는 장면에만 쓴다.
```

- 난이도 숫자와 시계 배정은 이 규칙 칸에만 있다. 메인 프롬프트에는 다시 쓰지 않았다.
- 시계 하나가 다 차는 데 보통 12일쯤 걸린다. 더 빠르게 하려면 clock을 1d4로 바꾸고 4를 '두 시계가 1칸씩'으로 정한다.

## 2. 상태창 컴포넌트

- 컴포넌트 칸에 이름 `Seonbongstatus`로 [Seonbongstatus.jsx](Seonbongstatus.jsx)를 통째로 붙여 넣는다.
- 디자인 없는 약식이다. 회색 상자에 글자만 나온다.
- 화면에 나오는 것: 국면, 날짜·시각·장소, 상황 한 줄, 장면 인물과 감정, 백일오의 기분, 판정 결과, 백일오 관계 수치(신뢰·필요·끌림), 신의 탐욕과 거래(값이 있을 때만), 사건 시계 셋, 전투 칸(ph_battle일 때만), 선택지 버튼(누르면 복사).
- 화면에 나오지 않는 것: `ties`(NPC 우정). AI만 읽고 이어받는 숨은 값이다.

## 3. 코드 정리

| 칸 | 형식 | 로어북 키워드로 쓰는가 |
|---|---|---|
| phase | `ph_d1`~`ph_d4`, `ph_daily`, `ph_mission`, `ph_battle`, `ph_purify`, `ph_nsfw`, `ph_event` | 쓴다 (국면별 문서, 아직 없음) |
| npcs | `c_baek`, `c_yo`, `c_muk`, `c_cheon`, `c_ah`, `c_kang`, `c_crow` + `:감정` | 쓴다 (`c_baek`, `c_crow`) |
| bonds | `baek:신뢰:필요:끌림` | 쓰지 않는다 (매 턴 찍힘) |
| ties | `yo:0` 등 네 명 | 쓰지 않는다 (매 턴 찍힘) |
| greed | 숫자 | 쓰지 않는다 |

## 4. 로어북 키워드가 상태창 글자로 켜지는지 시험

이 봇은 상태창 태그 속 글자로 로어북 문서를 불러오는 구조다. 유니챗 로어북이 AI 응답 속 글자도 읽는지 먼저 확인한다.

1. 로어북에 키워드 `ph_d1`로 "모든 대사 끝에 '냥'을 붙인다" 같은 티 나는 문서를 하나 만든다.
2. 테스트 채팅에서 첫인사 다음 턴을 받아 본다.
3. 대사 끝에 '냥'이 붙으면 이 구조로 간다. 안 붙으면 다른 방식이 필요하다.
4. 시험이 끝나면 그 문서를 지운다.
