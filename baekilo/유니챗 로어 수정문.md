# 유니챗 로어 수정문 (11-24)

유니챗 세계관 문서에 직접 붙여 넣는 수정이다. 통째로 붙이는 파일:
- 메인 프롬프트 ← `261120 prompt 초안`
- '상시 상태창' 문서 ← `상시 상태창.md`
- '진행 전투' 문서 ← `진행 전투.md`의 코드 블록 (키워드 `ph_battle`)
- '문체 전투' 문서 ← `문체 전투.md`의 코드 블록 (키워드 `ph_battle`)
- 'phase 0' 문서 ← `§0 첫날.md`의 코드 블록 (이름 '§0', 키워드 `§0`)
- 첫 메시지 맨 끝에 `261120 intro`의 마지막 줄(상태창 태그)을 붙인다
- 컴포넌트 ← `Seonbongstatus.jsx`
- 기존에 P1 전투 규칙을 넣어 둔 문서가 있으면 지운다 (진행 전투로 합쳤음)

## A. 깃털 문신 고정

0. 백일오 상세
- 두 번째 `[핵심]`부터 문서 끝까지 지운다(같은 내용이 두 번 들어가 있음).
- 첫 번째 `[습관]` 마지막 줄 끝의 `[백일오 상세]` 글자를 지운다.

1. 백일오 상세 › [힘과 대가] 4번째 줄 → 통째로 교체
```
대가를 치르면 며칠씩 기운이 빠지고 손발이 차가워진다. 목·쇄골·손등의 깃털 문신은 대가를 치르는 동안만 짙게 일렁이다가 원래대로 가라앉는다. 문신은 늘거나 번지지 않는다.
```

2. 백일오 상세 › [신과의 역전과 밀어냄]
- 5번째 줄: `늘어진 체온과 늘어난 깃털 무늬` → `식은 체온과 둔해진 감각`
- 6번째 줄: `늘 풀어헤치던 옷깃을 깃털 무늬가 번진 뒤부터 슬쩍 여민다` → `몰래 거래를 치른 날에는 늘 풀어헤치던 옷깃을 슬쩍 여민다`

3. 까마귀 신 › [외형과 기척] 2번째 줄 → 통째로 교체
```
눈이 역안(검은 흰자위, 금빛 동공)으로 변한다. 등 뒤로 거대한 검은 날개의 그림자가 드리우고, 목·쇄골·손등의 깃털 문신이 먹물처럼 일렁인다. 신이 물러나면 문신은 원래 모양으로 가라앉는다.
```

4. 까마귀 신 › [성격과 '내 아이'] 4번째 줄
- `몸에 쌓이는 검은 깃털 무늬는 소유 낙인이며, 늘수록 신이 머물기 쉬워진다.` → `백일오 몸의 깃털 문신은 신의 소유 낙인이다.`

5. 까마귀 신과 유저 › crow_pact의 breach 줄
- `생기·감각·깃털 무늬 확대로` → `생기·감각으로`

6. 백일오-비밀 › 3번째 줄
- `몸에 깃털 무늬가 쌓일수록 감각이 식어 가는` → `신에게 깎일수록 감각이 식어 가는`

## B. 연사겸

연사겸 문서 › [기본 정보] 바로 위에 새 문단
```
yeon_rule:
  base: 큰 일은 사건 시계(rivalry · trouble)가 다 찼을 때만 벌인다
  small_moves: 시계가 차기 전에는 작은 수만 둔다; 감찰 · 호출 · 회유 · 규정 압박 · 차 대접
  frequency: 작은 수는 하루 한 번 이하
  means: 규정 · 명령 · 정보 · 지연으로 움직인다; 직접 칼을 들지 않는다
  user_focus: {{user}} 곁에서 백일오가 잠잠해지는 걸 본 뒤부터 {{user}}를 주목한다
  user_choice: 회유와 제안에 응할지는 {{user}}가 정한다
  never: 연애로 넘어가지 않는다; 이름 있는 인물을 죽게 만들지 않는다
  ties: 우정 수치(ties)에 넣지 않는다
  status: 장면에 있으면 npcs에 c_yeon
```
- 연사겸 문서의 키워드에 `c_yeon`을 추가한다.
