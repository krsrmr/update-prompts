# 오손 상태창 v0.4 (261107~261109)

코드: [Orsonstatus.jsx](Orsonstatus.jsx) · 컴포넌트 이름 `Orsonstatus` · 유니챗 정적 검사 통과

## 바뀐 것

| 항목 | 내용 |
|---|---|
| 긴 글자 흘러가기 | 곡명, 아티스트, 장소, 출처, 날짜·시간 줄처럼 `…`로 잘리던 7곳이 칸을 넘으면 음원 앱처럼 왼쪽으로 흐른다. 처음 2초 멈춤 → 흐름 → 반복. 짧으면 그대로. 속도는 `OS_MARQ`(`speed`, `hold`) |
| 넓은 창 | 상태창 칸이 540px 이상이면 펼쳤을 때 스포티파이 PC풍 화면. 왼쪽: 메뉴(전체 / 지금 / 동네) + 턴테이블 재생 카드. 오른쪽: 요약 칩 + 위젯(오른쪽만 스크롤) |
| 메뉴 구성 | 지금 = 날짜·시간·날씨·장소·몸 상태 타일, 금주·금연, 지갑, 관계 앨범 / 동네 = 동네 사정, 크레딧, 작업대 위 / 전체 = 모두 |
| 요약 칩 | 관계 단계 → 오손의 감정(`mood`) → 몸 상태 첫 항목 → 날씨. 누를 수 없음. 값이 비면 안 보임 |
| 570px 대응 | 540~760px은 '좁은 넓은 창'(왼쪽 열 196px, 오른쪽 1열). 760px 이상은 2열 |
| 위 여백 | 상태창 위 48px(`<br/><br/>` 정도). 코드 끝쪽 `paddingTop: 48` |
| 관계 앨범 이미지 | 넓은 창의 관계 4단계 표지만 이미지 자리. `OS_IMG.stage`에 .webp 주소. 비우면 바이닐 그림, 잠긴 단계는 흐리게 가림 |
| 다음 곡(goal) | 넓은 창에서는 뺐다. 좁은 화면(폰)에는 그대로 |
| 훅 직접 연결 | `Test` 컴포넌트에서 `useRef is not defined` / `useState is not defined`가 떠서, 훅을 React에서 직접 꺼내 쓰게 바꿈(`osHooks`) |

크기 조절은 코드 중간 `OS_WIDE` 한 줄: `min` 넓은 창 기준 폭(540) · `full` 2열 기준 폭(760) · `h` / `hS` 높이(640 / 540) · `side` / `sideS` 왼쪽 열 폭(280 / 196).

## 메인 프롬프트 수정 (`## 상태창 출력 규칙`)

### 1. 감정 칩용 `mood` 추가

- 위치: `- goal: …` 줄 바로 아래

```text
- mood: 오손의 지금 감정 한두 단어. 상태창에만 쓴다. 예 "짜증", "멋쩍음"
```

- 위치: 맨 아래 `Example:` 줄의 `goal="…"` 바로 뒤

```text
 mood="짜증"
```

### 2. 컴포넌트 이름 되돌리기

테스트 중 `<Test/>`로 바뀌어 있던 두 곳을 `<Orsonstatus/>`로.

- `모든 응답의 맨 끝에 <Test/>를 한 번 출력한다.` → `모든 응답의 맨 끝에 <Orsonstatus/>를 한 번 출력한다.`
- `Example:` 줄 맨 앞 `<Test date=` → `<Orsonstatus date=`

### 3. (선택) 2020년대 곡 막기

- 위치: `- song / artist / source:` 줄
- 바꾸기 전: `이야기 시점 이전에 나온 실존 곡만 쓰고`
- 바꾼 후: `2019년까지 나온 실존 곡만 쓰고(2020년 이후 곡 금지)`

### 4. (선택) 노래 풀 넓히기

- 위치: `- song / artist / source:` 줄 맨 끝, `침묵 자체가 중요한 장면이면 song "무음".` 뒤에 이어 붙임

```text
출처마다 장르가 다르다: 매장 턴테이블은 60~70년대 포크·블루스·소울 중고판, 도티의 주크박스는 70~80년대 록, 라파의 라디오는 라틴(살사·바차타), 마리셀은 2010년대 팝·인디, 벤은 2010년대 신보, 오손의 헤드폰은 컨트리·아메리카나. BGM은 직전 BGM과 다른 장르와 연대에서 고른다. 최근 상태창에 나온 아티스트는 피한다.
```
