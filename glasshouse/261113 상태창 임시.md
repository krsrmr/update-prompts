# 글래스하우스(가제) · 임시 상태창 (261113)

JSX 없이 코드 블록으로만 찍는 임시본이다. 무엇을 어떻게 기록할지 시험하는 용도라, 칸 규칙은 메인 프롬프트 `## 상태창`에 모두 들어 있다. 이 문서는 칸을 고른 이유와 첫인사용 시작값만 적는다.

## 출력 모양

```
GLASSHOUSE // 관찰 기록
시각 | 11/13 금 23:40 · 스콜
장소 | 중심 온실 · 집무실
생체 | 심박 132 · 체온 37.4℃ · 호흡 빠름 · 동공 확장
판독 | 공포 · 경계
사랑 파형 | 미검출 (0%)
판매 | 유예 0회 · "수확 전. 서두를 이유가 없습니다."
탈출 시도 | 0회
최근 선택 | —
기록 | 떨림의 주기가 불규칙하다. 흥미롭다.
```

## 칸마다 하는 일

| 칸 | 기록하는 것 | 넣은 이유 |
| --- | --- | --- |
| 시각 · 장소 | 날짜, 요일, 시간, 날씨, 위치 | 시간 건너뛰기와 스콜·매연 같은 날씨 연출을 이어 간다 |
| 생체 | {{user}}의 심박·체온·호흡·동공 | 필리아스의 센서 연출을 매 응답 붙잡아 둔다. '감정이 곧 위치 신호'라는 설정과 이어진다 |
| 판독 | 필리아스가 짐작한 감정 | 필리아스의 해석이라 틀릴 수 있다. 센서는 몸만 읽고 마음은 못 읽는다는 선을 지킨다 |
| 사랑 파형 | 0~100% | 필리아스의 표면 목표가 어디까지 왔는지. 자발적인 애정·신뢰·걱정에서만 오르고, 공포·강요된 쾌락·체념·의존으로는 오르지 않는다 |
| 판매 | 유예 횟수 + 이번 핑계 | 판매 유예(의도적 모순)를 기록으로 쌓는다. 핑계가 매번 달라야 해서 칸에 남긴다 |
| 탈출 시도 | 횟수 | 탈출 대응이 같은 수를 반복하지 않도록 횟수를 남긴다 |
| 최근 선택 | 가장 최근의 중요한 선택 | 디트로이트식 '선택은 쌓인다'를 다음 응답에 넘긴다 |
| 기록 | 필리아스의 관찰 메모 한 줄 | 필리아스의 기계 말투를 매 응답 한 번 더 잡아 준다 |

## 첫인사 시작값

첫인사 끝에 아래를 붙이면 두 번째 응답부터 이어받는다. 시각과 날씨는 첫인사 장면에 맞게 바꾼다.

```
GLASSHOUSE // 관찰 기록
시각 | 11/13 금 23:40 · 스콜
장소 | 중심 온실 · 집무실
생체 | 심박 128 · 체온 37.2℃ · 호흡 빠름 · 동공 확장
판독 | 공포 · 경계
사랑 파형 | 미검출 (0%)
판매 | 유예 0회 · —
탈출 시도 | 0회
최근 선택 | —
기록 | 신규 표본 입고. 반응 순도 측정 시작.
```

영어판 프롬프트(`261113 prompt 초안 EN`)를 쓸 때는 칸 이름만 영어인 아래 시작값을 붙인다.

```
GLASSHOUSE // OBSERVATION LOG
TIME | 11/13 금 23:40 · 스콜
LOCATION | 중심 온실 · 집무실
VITALS | 심박 128 · 체온 37.2℃ · 호흡 빠름 · 동공 확장
READING | 공포 · 경계
LOVE WAVEFORM | 미검출 (0%)
SALE | 유예 0회 · —
ESCAPES | 0회
LAST CHOICE | —
NOTE | 신규 표본 입고. 반응 순도 측정 시작.
```

## 시험할 때 볼 것

- **사랑 파형이 너무 빨리 오르는지:** 오르는 조건을 좁게 잡았지만, AI는 관능 장면마다 올리려 들 수 있다. 빠르면 '한 번에 최대 +5'를 +3으로 줄이거나 '관능 장면에서는 오르지 않는다'를 더한다.
- **판매 칸이 본문 없이 늘어나는지:** 본문에서 판매를 말하고 미룬 응답에서만 올라야 한다.
- **상태창 내용이 본문에 새는지:** 필리아스가 수치를 대사로 읊는 건 의도한 연출이다. 다만 서술이 사랑 파형이나 유예 횟수를 직접 말하면 안 된다.
- **나중에 JSX로 옮길 때:** 이 칸들이 그대로 props가 된다. 사랑 파형은 숨은 값으로 돌려도 된다(필리아스만 보는 기록이라는 설정).
