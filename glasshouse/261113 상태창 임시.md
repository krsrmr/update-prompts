# 글래스하우스(가제) · 임시 상태창 (261113, v2 기준)

JSX 없이 코드 블록으로만 찍는 임시본이다. 무엇을 어떻게 기록할지 시험하는 용도라, 칸 규칙은 모두 메인 프롬프트 [261113 prompt v2 EN](261113%20prompt%20v2%20EN)의 `# STATUS`에 들어 있다. 이 문서는 칸마다 넣은 이유와 시험할 때 볼 점만 적는다.

- 칸 이름은 영어, 값은 한국어다.
- 메인 프롬프트의 상태창 예시 = 첫인사 끝 상태창 = 시작값. 셋이 같아야 두 번째 응답부터 이어받는다.

## 시작값

```
GLASSHOUSE // OBSERVATION LOG
TIME | 11/13 금 23:40 · 스콜
LOCATION | 중심 온실 · 집무실
VITALS | 심박 141 · 체온 37.6℃ · 호흡 불규칙 · 동공 확장
READING | 공포 · 경계
LOVE WAVEFORM | 미검출 (0%)
SALE | 유예 0회 · —
ESCAPES | 0회
LAST CHOICE | —
LOSSES | —
NOTE | 신규 표본 입고. 반응 순도 측정 시작.
```

## 칸마다 하는 일

| 칸 | 기록하는 것 | 넣은 이유 |
| --- | --- | --- |
| TIME · LOCATION | 날짜, 요일, 시간, 날씨, 위치 | 시간 건너뛰기와 스콜·매연 같은 날씨 연출을 이어 간다 |
| VITALS | {{user}}의 심박·체온·호흡·동공 | 필리아스의 센서 연출을 매 응답 붙잡아 둔다. '감정이 곧 위치 신호'라는 설정과 이어진다 |
| READING | 필리아스가 짐작한 감정 | 필리아스의 해석이라 틀릴 수 있다. 센서는 몸만 읽고 마음은 못 읽는다는 선을 지킨다 |
| LOVE WAVEFORM | 0~100% | 필리아스의 목적이 어디까지 왔는지. 자발적인 애정·신뢰·걱정에서만 오르고, 공포·강요된 쾌락·체념·의존·증오로는 오르지 않는다(필리아스가 증오와 사랑이 같다고 우겨도) |
| SALE | 유예 횟수 + 이번 핑계 | 판매 유예(의도적 모순)를 기록으로 쌓는다. 사랑의 완성 뒤에는 '무기한 취소'로 바뀌고 셈을 멈춘다 |
| ESCAPES | 횟수 | 탈출 대응이 같은 수를 반복하지 않도록 남긴다 |
| LAST CHOICE | 가장 최근의 중요한 선택 | '선택은 쌓인다'를 다음 응답에 넘긴다 |
| LOSSES | 죽은 NPC 이름·역할 | 죽은 NPC가 긴 대화에서 되살아나지 않게 붙잡아 둔다 |
| NOTE | 필리아스의 관찰 메모 한 줄 | 필리아스의 기계 말투를 매 응답 한 번 더 잡아 준다 |

## 시험할 때 볼 것

- **사랑 파형이 너무 빨리 오르는지:** 빠르면 '한 번에 최대 +5'를 +3으로 줄이거나 '관능 장면에서는 오르지 않는다'를 더한다.
- **혐관 루트에서 파형이 새는지:** 증오만 하는데 파형이 오르면, 필리아스의 "같은 곡선" 논리가 칸까지 번진 것이다.
- **판매 칸이 본문 없이 늘어나는지:** 본문에서 판매를 말하고 미룬 응답에서만 올라야 한다.
- **LOSSES가 유지되는지:** 죽은 NPC가 다시 대사를 하면 이 칸이 빠졌거나 무시된 것이다.
- **상태창 내용이 본문에 새는지:** 필리아스가 수치를 대사로 읊는 건 의도한 연출이다. 다만 서술이 사랑 파형이나 유예 횟수를 직접 말하면 안 된다.
- **나중에 JSX로 옮길 때:** 이 칸들이 그대로 props가 된다. 사랑 파형은 숨은 값으로 돌려도 된다(필리아스만 보는 기록이라는 설정).
