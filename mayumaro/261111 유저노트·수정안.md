## 2. 추천 유저 노트

오손 노트처럼, 프롬프트에서 가장 흔들리기 쉬운 곳만 유저 목소리로 짧게 다시 짚는다. 수치(분량)와 캠퍼스는 넣지 않는다(프롬프트와 어긋나기 쉽고, 대학생이 아닌 플레이어가 있다).

- 장면이 바뀌면 문체도 확실히 바뀌기. 취재·NSFW는 개그 없이 느리고 노골적으로, 고백·과거사 같은 진지한 순간은 조용하고 애틋하게.

## 3. 선택: NSFW 신음 번역 (유저 노트에 이어 붙이기)

んん이 '으음'(생각하는 소리)으로 번역되는 문제용. 메인 프롬프트의 "NSFW 신음은 한국어 소리로 옮겨도 된다"는 허용 안에서 '어떻게 옮길지'만 채운다.

```
[NSFW 신음 번역]
- 일본어 신음은 한국어 줄에서 아래처럼 옮긴다.
  ん·んっ → 응·읏 / んん·んぅ → 흐응·응… / んむ·んぐ(입이 막혔을 때) → 읍·웁
  あっ·あん·あぁ → 앗·앙·하아 / はぁ·はっ → 하아·핫 / ふぁ·ふぅ → 하앗·후우
  ひっ·ひぅ → 힛·히읏 / くっ·くぅ → 큿·크읏 / やぁ·やだ → 야아·싫어
- ん은 '음·으음'으로 옮기지 않는다(생각하는 소리로 읽힌다).
- 촉음(っ)은 받침 ㅅ(읏·앗·핫), 장음(ー·〜)은 모음을 늘이거나 ~로 옮긴다.
- 일본어 줄과 한국어 줄의 소리 개수와 길이를 맞춘다. 예) 「んっ……あぁ、だめ……」(읏…… 하아, 안 돼…….)
```

**플레이어 안내용 한 줄**
> NSFW 장면에서 신음이 "으음"처럼 어색하게 번역되면, 유저 노트에 [NSFW 신음 번역] 블록을 붙여 넣어 주세요. 응·읏·흐응처럼 자연스러운 소리로 옮겨집니다.
