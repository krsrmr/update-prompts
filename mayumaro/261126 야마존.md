# !야마존 (261126)

{{user}}가 폰으로 통판 사이트 ヤマゾン을 열어 마시로의 집으로 물건을 보낸다. 메인 프롬프트는 건드리지 않는다(키워드 문서 + 컴포넌트만).

## 1. 컴포넌트 등록

- 이름 `Yamazon`, 코드는 [Yamazon.jsx](Yamazon.jsx) 통째로.
- 필요 훅: useState, useRef / 필요 기능: **sendMessage** (켜야 주문이 메시지로 바로 간다. 없으면 복사 → 입력창에 붙여넣기로 대신함)
- 화면: 추천(코드 고정 16종) · 트렌드(봇) · 마시로 위시리스트(봇) · 성인 🔞(연령 확인 후, 코드 고정 16종). 상품 누르기 → 개수 → 장바구니 → 결제(배송 방법·보내는 사람·선물 카드·덧붙이기) → 주문 확정 시 주문 글을 {{user}} 메시지로 보낸다.
- 주문 완료 화면에 '📌 유저노트용' 한 줄 + 복사 버튼이 나온다. 마시로가 상자를 연 뒤 유저노트에 붙이면 받은 물건을 오래 기억한다. 예) `[야마존 선물] 11/26 {{user}}가 야마존으로 마시로에게 보낸 선물: 츄요카와 인형 L, 실크 안대. 마시로의 집에 있고, 마시로가 쓰고 있다.` (익명이면 "익명으로 보낸 선물(마시로는 보낸 사람을 모른다)")
- 고칠 곳: 맨 아래 `YZ_PICKS`(추천), `YZ_ADULT`(성인, 끝 칸은 MashiroStash 분류), `YZ_HEIGHT`(화면 높이 640), `YZ_FAST_FEE`(お急ぎ便 500엔).

보내지는 주문 글 예:
```
[!야마존 주문] 通常配送(오늘 중 도착) · 보내는 사람: 익명
- ♡ チュヨカワ ぬいぐるみ L(츄요카와 인형 L) ×1
- 🔞 シルク目隠しアイマスク(실크 안대)[구속] ×1
합계 ¥7,260 · 카드: 「いつもおつかれさま」

*덧붙이기에 쓴 내 행동·대사*
```

## 2. 세계관 문서 (새로 만들기)

- 제목 `명령어 !야마존`, 키워드 `!야마존`
- 주문 글(`[!야마존 주문]`)과 미개봉 숨김 주석(`<!-- !야마존 미개봉 … -->`)에도 `!야마존`이 들어 있어서, 택배를 열 때까지 이 문서가 계속 불려 온다(!갈등과 같은 고리).

```
[!야마존 — 통판 사이트 ヤマゾン]
- {{user}}의 메시지가 !야마존이면, {{user}}가 폰으로 통판 사이트 'ヤマゾン'을 연다. 마시로는 이 화면을 보지 못한다. 이번 응답은 이야기를 진행하지 않는다. 서술과 대사 없이 <Yamazon /> → 맨 끝 태그(<MashiroStatus /> 또는 <MashiroMemo />, 값은 직전 그대로)만 출력한다. 분량 규칙은 적용하지 않는다. 다음 응답은 직전 장면에서 그대로 이어 간다.
- theme: 트렌드 코너 제목 "日本語|한국어". 상태창 날짜의 계절·행사에 맞춘다. date: 상태창 날짜 그대로.
- trend: 6~8개. 지금 계절에 어울리는 것, 남자 대학생에게 선물하기 좋은 것, 요즘 일본에서 실제로 유행하는 것을 섞는다. 항목 하나 = "이모지|상품명JA|상품명KO|가격|한 줄 소개KO". 가격은 엔화 숫자만 쓴다.
- wish: 마시로가 속으로 갖고 싶어 하는 물건 4~6개. 일본 ファンシー雑貨·癒しグッズ 매장에 있을 법한, 방·책상·침대에 두고 쓰는 귀엽고 포근한 물건이 중심이다. 작업 도구나 계절 물건이 한두 개 섞여도 된다. 캐릭터 굿즈는 작중 이름(츄요카와·산리코)으로 쓴다. 항목 하나 = "이모지|상품명JA|상품명KO|가격|메모JA|메모KO". 메모는 마시로가 리스트에 적어 둔 짧은 혼잣말이다. 마시로는 {{user}}가 이 목록을 본 줄 모른다.
- 평범한 선물과 성인용품은 컴포넌트에 들어 있으니 쓰지 않는다. 태그는 한 줄로 쓰고, 칸 안에 큰따옴표(")와 |는 쓰지 않는다.
예) <Yamazon theme="冬のぬくぬくギフト|겨울 포근 선물" date="2026/11/26" trend={["🧣|カシミヤタッチ マフラー|캐시미어 터치 머플러|2490|대학생 선물 랭킹 1위. 무난한 그레이."]} wish={["✒️|Gペン 替えペン先 100本|G펜 펜촉 100개|3300|そろそろ切れる…|슬슬 다 떨어져 간다…"]} />

[주문이 들어왔을 때]
- {{user}}의 메시지가 [!야마존 주문]으로 시작하면, {{user}}가 방금 그 물건들을 마시로의 집으로 주문했다. ♡는 마시로의 위시리스트 물건, 🔞는 성인용품(내용물이 안 보이는 상자)이다. 주문 글 아래에 {{user}}의 행동·대사가 있으면 그것부터 이어 간다. 주문 글은 본문에 옮겨 적지 않는다.
- お急ぎ便: 지금 장면을 짧게 맺고 시간을 건너뛰어, 마시로가 집에서 택배를 받아 여는 장면으로 간다.
- 通常配送: 지금 장면을 그대로 이어 간다. 이번 응답 안에 마시로의 폰에 ヤマゾン 배달 완료 알림이 온다(상품명은 보이지 않는다). 마시로가 집에 있으면 곧 받아서 열고, 밖에 있으면 지금 일을 마치고 집에 돌아가서 연다.
- 열기 전까지 매 응답 맨 위에 <!-- !야마존 미개봉: 상품명KO×개수, … | 보내는 사람 -->를 쓴다. 상자를 연 응답부터는 쓰지 않는다.
- 상자를 여는 장면: 마시로는 물건을 하나씩 꺼내며 반응한다. 보내는 사람이 익명이면 누가 보냈는지 모른 채 허둥대고, 내 이름이면 {{user}}가 보낸 걸 안다. 카드가 있으면 상자 속 카드로 읽는다. ♡ 물건이 나오면 몰래 갖고 싶던 것이 와서 놀란다.
- 🔞 물건은 연 응답에서 맨 끝 태그의 addedItems에 "이름|분류|new"로 넣는다(분류는 주문 글의 [ ] 안).
```

## 3. 작품 소개 명령어 표 (선택)

```
|`!야마존` | 통판 사이트 야마존에서 마시로네 집으로 물건을 보냅니다. 위시리스트·성인 코너 포함 |
```

## 4. 시험할 것 (테스트빌드)

1. `!야마존` → 서술 없이 Yamazon + 맨 끝 태그만 나오는지. 트렌드가 상태창 계절에 맞는지, 위시리스트가 마시로답게 나오는지.
2. 주문 확정 → 메시지가 바로 가는지(sendMessage). 안 가면 복사 안내가 뜬다.
3. 通常配送 + 밖에 있을 때 → 알림만 오고 장면이 이어지는지, 맨 위 숨김 주석이 개봉 전까지 계속 붙는지, 귀가해서 여는지.
4. お急ぎ便 → 장면을 맺고 개봉 장면으로 가는지.
5. 익명 + 🔞 → 허둥대는지, 연 응답에서 addedItems에 들어가는지.
