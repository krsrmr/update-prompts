# 마유마로 — 포키데이 이벤트 `!포키` (초안)

v8.2 기준. 메인 프롬프트는 **한 줄만 추가**한다(전체 교체 아님).

**하는 일**
- `!포키`를 보내면 이야기가 11월 11일(ポッキーの日)로 건너뛴다. 마시로가 "작업 중인 화의 포키 게임 장면 자료"라며 포키 게임을 부탁한다.
- 결말은 관계 단계로 갈린다. 연인이 되기 전에는 입술이 닿기 전에 마시로가 기권하거나 포키가 부러진다. 연인이면 끝까지 갈 수 있다.
- 한 판이 끝나면 결과 카드 `<PockyGame />`이 나온다. 두 사람(카오모지)이 한 입씩 다가가는 재생, 남은 거리(mm) 자, 판정 도장(棄権 / ポキッ / ♡成功), 마시로 심박, 마시로 메모.
- `!포키 딸기`처럼 맛을 붙일 수 있다. 딸기·말차·아몬드·극세·화이트는 카드의 포키 색이 바뀐다.
- 결과 그림 3장(기권·부러짐·닿음)을 넣을 자리가 있다. 비워 두면 그림 없이 나온다.

정해 둔 기본값(바꿀 수 있음)
- **본편**으로 진행한다. 이야기 날짜가 실제로 11/11이 되고, 관계도 그대로 이어진다.
- 글에서는 실제 이름 ポッキー를 쓴다. 그림에는 상표·포장·글자를 넣지 않는다.
- 결과는 AI가 정하고, 카드는 재생만 한다.

## 2. 세계관 문서 새로 만들기

- 제목: `명령어 !포키`
- **상시 끄기**, 키워드 `!포키`, `PockyGame`
- `PockyGame`은 보조 키워드다. 한 판 더 할 때 직전 응답의 카드 태그로 문서가 다시 불려 오게 한다(`LimeChat`과 같은 방식).

```
[!포키 — 포키데이(ポッキーの日)]
- {{user}}의 메시지가 !포키로 시작하면 이야기 밖의 명령어다. 지금 장면을 한두 문단으로 정리하고 11월 11일(ポッキーの日)로 건너뛴다. 이야기 날짜가 이미 11월 11일을 지났으면 날짜는 그대로 두고, 할인 매대에 남은 ポッキー 같은 계기를 만든다.
- !포키 뒤에 맛이 붙어 있으면 그 맛, 없으면 초코. 딸기는 달콤한 향, 극세는 가늘어서 잘 부러짐, 아몬드는 오도독 소리.
- 마시로는 작업 중인 화(episode)의 포키 게임 장면 자료라며 {{user}}에게 포키 게임을 부탁한다. 부탁하지 못하고 머뭇거리면 {{user}}가 먼저 꺼낼 틈을 만든다. 한 판은 이번 응답 안에 끝낸다.
- {{user}}가 승낙해 게임이 시작되면 취재다. 게임 중인 응답은 researching={true}로 쓰고, 취재·NSFW 무드로 느리게 쓴다: 한 입씩 줄어드는 거리, 숨, 안경, 귀까지 번지는 열.
- 결말은 지금 관계로 정한다.
  - phase 1~2: 마시로가 금방 기권하거나 자기가 부러뜨린다. 남은 거리 60mm 이상.
  - phase 3 이상, dating={false}: 입술이 닿기 전에 마시로가 기권하거나 포키가 부러진다. 남은 거리 3~30mm.
  - dating={true}: {{user}}가 피하지 않으면 끝까지 가서 입술이 닿는다. 남은 거리 0.
  - {{user}}가 먼저 놓거나 부러뜨리면 그 결과를 따른다.
- 출력 순서: 서술 → <PockyGame /> → 맨 끝 태그(<MashiroStatus /> 또는 <MashiroMemo />). 게임을 하지 않고 끝난 응답엔 <PockyGame />을 내지 않는다.
- 같은 장면에서 한 판 더 하면 명령어 없이도 같은 형식으로 <PockyGame />을 낸다.
- PockyGame 값: date 이야기 날짜. flavor 맛 이름. left 남은 거리(mm, 0~135). result 기권/부러짐/닿음. by 기권하거나 부러뜨린 사람(마시로 또는 {{user}}, 닿음이면 생략). bpm 마시로의 최고 심박(90~190). mashiroFace, userFace 그 순간의 카오모지. userName {{user}}. memo 마시로의 메모 30자 안팎, 진지한데 민망함이 새어 나오는 말투.
예) <PockyGame date="11/11" flavor="딸기" left={12} result="기권" by="마시로" bpm={158} mashiroFace="(>﹏<)💦" userFace="(・ω・)" userName="{{user}}" memo="12mm. 안경이 먼저 닿는다. 콘티 수정 필요" />
```

## 3. 메인 프롬프트 — 한 줄 추가

**위치:** `## Component Output Rules`의 `- Jump commands:` 목록 맨 끝, `` - `!로맨스`: in the current scene, cause one chance incident …`` 줄 **바로 아래**.

```
  - `!포키` (a flavor may follow): Pocky Day event. Follow world doc [명령어 !포키]; its output order overrides the rules above.
```

- 줄 맨 앞 공백 두 칸까지 그대로 붙인다(위 `!로맨스` 줄과 같은 들여쓰기).

## 6. 결과 그림 (선택)

- 프롬프트: `pixai-prompts/pocky-results.md` (기권·부러짐·닿음 3장, 1:1)
- 기존 특전 그림 `pixai-prompts/scene-pocky-day.md`(햄스터 잠옷)는 이 카드와 별개다.
- 그림을 넣는 법
  1. 공개 저장소 `krsrmr/mayumaro`의 `img/` 폴더에 `pocky-giveup.webp`, `pocky-break.webp`, `pocky-touch.webp`로 올린다.
  2. 깃허브 Pages를 켠다(Settings → Pages → main / root).
  3. `PockyGame` 코드 맨 위 `PG_IMG`의 따옴표 안에 주소를 넣는다. 예) `기권: "https://krsrmr.github.io/mayumaro/img/pocky-giveup.webp",`
- 유니챗 미리보기에서 바깥 주소의 그림이 뜨는지는 아직 확인 전이다. 안 뜨면 그림 칸만 비워 두면 된다.

## 7. 붙여넣은 뒤 확인할 것

- [ ] `!포키`를 보내면 11/11 장면으로 넘어가고, 서술 → 카드 → 상태창 순서로 나오는지. 대사로 받아치면 키워드가 안 걸린 것이다(그때는 키워드를 `포키`로 바꿔 본다)
