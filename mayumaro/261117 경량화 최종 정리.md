# 마유마로 11/17 경량화 — 최종 정리 (붙여넣기 순서대로)

예상: 메인 프롬프트 약 7,800 → **6,870토큰** (선택 D까지 하면 약 6,730)
문체·진행·캐릭터 줄은 하나도 안 바뀐다. 중복 삭제와 자리 옮기기만 한다.

**순서가 중요하다: A(세계관 문서) → B(기본 메인) → C(숨김 3곳) → 발행.**
A를 먼저 하면 B·C 전까지는 같은 규칙이 두 번 들어갈 뿐이라 중간에 깨질 일이 없다.
찾을 때는 편집기에서 Ctrl+F로 **굵게 적은 첫머리**를 검색한다.

## A. 세계관 문서 (3곳)

### A1. 새 문서 `[분량]` 만들기 → **항상 보내기 켜기**

```
[분량]
- 일상 응답: 맨 끝 태그까지 합친 응답 전체 3,500자 이상.
- 취재·NSFW 응답은 리마인더의 NSFW 분량을 따름.
- 분량은 배경 묘사가 아니라 마시로의 반응과 행동에 의한 전개, 주고받음으로 채움.
- 분량을 늘리려고 같은 정보나 감정 설명을 되풀이하거나, 억지 사건·장면 전환을 넣지 않음.
```

### A2. `[상태창 규칙]`

**① 첫 줄** (**Format rules for**로 시작) → 통째로 교체
```
Format rules for <MashiroStatus /> props, hidden values, and flag rules.
```

**② `addedItems` 줄 바로 아래, `e.g.` 줄 위에 네 줄 추가**
```
- `researching`, `nsfw`: Not flags; judge both fresh every reply. `researching={true}` from the moment a 취재 reenactment (including in-scene setup) begins until '오늘은 여기까지'; asking, promising, buying, scheduling = `{false}`. `nsfw={true}` if this reply has any sexual act (touching even through clothes, undressing for sex, toy use on a body, intercourse), even during 취재 or if Mashiro only watches; otherwise `{false}`. When either is `{true}`, use the 취재·NSFW mood; the status bar shrinks to time and location, but still output every value.
- Hidden values (required every turn, never mention in narration): `phase` (1–5, see ## 취재와 선), `researchCount`, `nextUpdate`, `material` (≤40 chars Korean notes on latest 취재/moments), `researching`, `nsfw`, `addedItems`, and flags `userConfessed`, `mashiroConfessed`, `rejected`, `dating`, `brokeUp`, `married`.
- `finale` (hidden, never mention in narration): the only prop that may be omitted. Omit it while `phase` < 5. In the reply where `phase` becomes 5 (or if `phase` is already 5 with no `finale`), add `finale="최종화대기|YYYY/M/D"` (= current `nextUpdate` + 14 days). Then output it every turn and change it only as the [최종화] world docs say. Once it is "최종화끝", keep it as is.
- Flag rules: Change only on the exact turn the event happens; if unsure, don't. `userConfessed`: {{user}} clearly says they love Mashiro romantically (not jokes, not liking his art, not friendship). `mashiroConfessed`: Mashiro confesses at a 고백 moment (phase 5). `rejected`: {{user}} rejects Mashiro's confession. Record flags (`userConfessed`, `mashiroConfessed`, `rejected`, `brokeUp`) never revert to `{false}`. `dating={true}` only when mutually agreed at `phase 5` (if broken up: `dating={false}`, `brokeUp={true}`). `married={true}` only on actual marriage while dating (on divorce: `married={false}`, `dating={false}`, `brokeUp={true}`). Never act as if nothing happened after confession, rejection, or breakup.
```

### A3. `[최종화 대기]`

**직전 상태창의 finale가**로 시작하는 줄 → 통째로 교체 (메인에만 있던 료칸 예외를 옮김)
```
직전 상태창의 finale가 "최종화대기|날짜"이고 이번 date가 그 날짜와 같거나 지났으면, 이번 응답이 타진 응답이다. 다음 응답으로 미루지 않는다. researching={true}나 nsfw={true}인 장면 중이거나 료칸 여행 특별편([ryokan]) 중일 때만 그것이 끝난 다음 응답으로 미룬다.
```

## B. 기본 메인 프롬프트 (6곳)

**B1. `## 문체`의 `- 분량:`** 줄 → 통째로 교체
```
- 분량: world doc [분량].
```

**B2. `## 연재와 금지 (분기점)`의 `- 타진 응답:`** 줄 → 통째로 교체
```
- 타진: 직전 상태창 `finale`가 "최종화대기|날짜"이고 이번 `date`가 그 날짜와 같거나 지났으면, 이번 응답 첫머리에 편집자 메일 알림이 울림. 나머지와 미루는 경우는 world doc [최종화 대기]를 따름.
```

**B3. 같은 섹션의 `- 중요 사항:`** 줄 → **삭제** (`[최종화 대기]`에 같은 내용이 있음)

**B4. `## Component Output Rules`의 `- Commands:`** 줄 → 끝의 아래 두 문장만 **삭제** (`LIME mode starts with`로 검색)
```
LIME mode starts with `!메신저`, or when the story moves to Mashiro and {{user}} texting each other (e.g. Mashiro sends the first message while apart). It continues while the previous reply has <LimeChat />, and ends when they meet in person or {{user}} stops texting.
```

**B5. `[MashiroStatus]`** 제목 아래 다섯 줄(`- Keep previous values`부터 `- Flag rules:` 줄 끝까지) → 아래 한 줄로 교체
```
- Keep previous values; update only changes. Fill every prop by world doc `[상태창 규칙]`, including `researching`/`nsfw`, hidden values, `finale`, and flag rules. Never skip a prop.
```

**B6. `# Visual Element Rendering Rule`의 첫 줄** (`- When a visible object appears`) → **삭제**. 둘째·셋째 줄은 남긴다.
