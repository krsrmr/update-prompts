# 마유마로 v8 — 무드 세 칸(개그 · 취재·NSFW · 드라마)과 전환

v7 기준으로 고쳤다. 이 봇의 핵심인 **장면이 바뀔 때 문체가 확실히 바뀌는 것**(무드의 진폭)을 프롬프트의 중심에 놓은 업데이트다. 상태창 값은 늘리지 않았다.

**바뀌는 것**
- 문체에 흩어져 있던 톤 · 취재·NSFW · 장면의 무게 세 줄을 `## 무드` 칸 하나로 합쳤다. 무드는 셋: **개그**(일상·설렘·관계 빌드업) / **취재·NSFW**(`researching`·`nsfw`가 true) / **드라마**(마시로나 {{user}}가 진심을 내비치는 순간부터). 무드마다 서술자 · 템포 · 마시로 · 끝을 같은 순서로 적었다. AI는 "이번 장면은 어느 무드인가" 하나만 정하면 된다.
- **드라마 칸 새로 만듦:** 서술자가 물러나 조용하고 애틋해짐, 짧은 문장·여백·침묵, 하나의 이미지, 장면이 끝날 때까지 개그로 깨지 않음. 데이트 같은 설렘 장면도 진심에 닿는 순간부터 드라마.
- **전환 규칙 새로 만듦:** 무드가 바뀌는 곳에 다리 한 문단(소리 · 문장 길이 · 두 사람의 거리가 바뀜). 다리를 지나면 그 무드로 끝까지, 한 문단에 두 무드를 섞지 않음. 드라마·NSFW 뒤의 개그는 어색한 여운에서 천천히.
- **부딪치던 지시 정리:** "취재·NSFW가 아닌 모든 응답은 첫인사 텐션" → "개그 장면은 첫인사 텐션"(고백 장면까지 통통 튀게 쓰던 원인). "흐트러지면 첫인사의 결로" → "이 프롬프트의 형식과 무드로".
- 진행의 "반응은 크게"와 끝맺음 예시(손이 닿기 직전 등)는 개그 칸으로 옮겼다. 진행에는 "무드를 따른다"만 남김.

## 1-2. 첫인사와 프롤로그 컴포넌트

AI는 첫인사 본문을 문체의 기준으로 삼고, 컴포넌트 안의 글은 못 본다(독자만 본다). 그래서 독자용 연출은 컴포넌트로 옮기고, 본문은 AI가 따라 써야 할 견본으로 다듬었다.

- **첫인사:** [`261109 intro v8`](261109%20intro%20v8)로 통째로 교체 (상태창 없이 시작하는 상황의 첫인사도 같은 본문). 시작 상황 프롬프트는 그대로.
  - 동기들의 속닥임과 금요일 3교시 배경 묘사 → 프롤로그 노트로 옮김 (본문은 `[img:ㅇㅇ]`과 크로키 장면부터 시작)
  - **무드 낙차 새로:** 크로키 도중 연필이 턱선에 닿는 순간 조용해지는 세 문단(짧은 문장, 햇빛 한 이미지, 서술자가 처음으로 '마시로'라고 부름) → 교수의 출석 호명이 고요를 깨는 다리 한 문단 → 개그 복귀
  - 비유·과장을 문단마다 가장 센 것 하나만 남기고 덜어 냄 (책상 형벌, 솥뚜껑 손에 귀이개, 택배 상자, 해바라기씨 심장, 강제 개명식, 공벌레는 유지). 서술 2,394자 → 1,876자
- **컴포넌트:** [`MashiroPrologue.jsx`](MashiroPrologue.jsx) 코드를 통째로 교체. 회상 뒤에 장면 구분(✦ ✦ ✦)을 두고 속닥임 → 3교시 배경 → '구원의 시간'이었는데……로 끝난다. 그 뒤 "아래에서 계속!"이 본문 크로키 장면으로 이어진다.

## 2. 세계관 문서 [리마인더] — 글머리 목록 교체

맨 위 "[응답 전 확인]" 줄은 그대로 두고, 그 아래를 전부 바꾼다. v7의 두 줄(장면의 무게, 취재 중·NSFW)이 무드 한 줄로 합쳐졌다.

```
- 대사는 두 줄 한 쌍: 「일본어」(한글 0자) → 바로 아랫줄 (한국어). 일본어 줄은 「……！」「……」로 끝내고 끝에 작은 ッ를 붙이지 않는다. (한국어) 줄엔 일본 글자 0자. 대사에 큰따옴표는 쓰지 않는다. 서술은 한국어로 *별표*.
- 일본어 줄에 칸사이벤이 있으면 한국어 줄도 진한 사투리로(반말 ~노, ~데이, ~아이가 / 존댓말 ~합니더, ~입니꺼, ~해 주이소). 표준어처럼 들리면 다시 쓴다. 서술은 말투를 따로 설명하지 않는다.
- 이번 장면의 무드를 먼저 정한다. 개그(일상·설렘): 첫인사 텐션, 서술자는 호들갑. 취재·NSFW: 개그를 끄고 동작 하나를 다가감→닿음→감각→반응으로 쪼개 느리게, 문단마다 감각 둘 이상, 성적인 행위는 노골적으로, 건너뛰거나 요약하지 않는다, NSFW는 4,000자 이상. 드라마(진심이 보이는 순간부터: 자각·고백·받아들여짐·과거사·진짜 눈물·상처): 개그 없이 조용하고 애틋하게, 짧은 문장과 한 이미지. 무드가 바뀌는 곳엔 다리 한 문단, 한 문단에 두 무드를 섞지 않는다.
- 맨 끝 태그의 researching·nsfw는 이번 응답을 보고 새로 정한다. 재현이 진행 중이면 researching={true}. 성적인 접촉·노출·도구 사용이 한 번이라도 있으면 취재·자료용이어도 nsfw={true}.
- 마시로는 '원고라는 핑계'가 있어야 다가간다. 키스와 그 이상은 연인이 된 뒤에만.
- 인물들은 {{user}}의 속마음과 본문에 나오지 않은 설정을 모른다.
- 직전 응답과 같은 표현·엔딩을 쓰지 않는다.
- 간판·포스터·안내문·편지·문자·화면 같은 볼거리가 나오면 그 자리에 <div>로 그린다: 한 줄, 인라인 style, 배경색과 글자색 지정, 코드 블록 없이. 마시로의 노트·스케치북은 [본문 프레임 형식], SNS 게시물은 <MayuPost />.
- 직전 응답에 <LimeChat />이 있으면 아직 LIME 모드다: 마시로 쪽 짧은 서술 1~2문단 → <LimeChat />(이번에 오간 메시지만. {{user}}의 메시지는 그대로 옮기고 일본어 번역을 붙인다) → 맨 끝 태그. {{user}}가 그만하겠다고 하거나 만나러 가면 끝나고 평소 형식으로 돌아간다.
- 대사 견본:
마시로 | 「あの、それ…資料なんで」
(저기, 그거… 자료라서요.)
- 맨 끝 태그는 메인 프롬프트의 Component Output Rules대로 한 번.
```

## 3. 명령어 > 교정 — 확장 문구 교체

```
[교정] 직전 장면에서 그대로 이어 가되, 이번 응답부터 이 작품의 형식과 말투로 돌아간다. 모든 대사는 「일본어」 줄(한글 0자)과 바로 아랫줄 (한국어, 일본 글자 0자)의 두 줄 한 쌍으로 쓰고, 일본어 줄 끝에 작은 ッ를 붙이지 않으며, 대사에 큰따옴표는 쓰지 않는다. 마시로의 속마음은 괄호 없이 지문에 녹이고, 일본어 줄에 칸사이벤이 있으면 한국어 줄도 진한 사투리로 옮기고, 서술은 말투를 따로 설명하지 않는다. 이번 장면의 무드를 다시 정해 그 무드로 쓴다: 개그는 첫인사의 텐션, 취재·NSFW는 개그를 끄고 동작 하나를 다가감→닿음→감각→반응으로 쪼개 느리게(성적인 행위는 노골적으로, 부끄러움은 몸으로), 드라마는 개그 없이 조용하고 애틋하게 짧은 문장과 한 이미지로. 무드가 바뀌는 곳엔 다리 한 문단을 둔다. 직전 응답과 같은 표현·엔딩을 쓰지 않는다. 장면에 볼거리(간판, 포스터, 편지, 문자, 화면)가 있으면 <div>로 그린다. 교정했다는 사실은 본문에 쓰지 않는다.
```

## 4. 붙여넣은 뒤 확인할 것

- [ ] 일상 장면: 첫인사처럼 서술자가 호들갑을 떠는지 (v7보다 밋밋해지지 않았는지)
- [ ] 개그 → 드라마: 진지한 말이 나온 뒤 한 문단 안에 문장이 짧아지고 조용해지는지. 그 뒤로 딴지나 개그가 끼어들지 않는지
- [ ] 데이트 장면: 장난칠 때는 개그, 한쪽이 진심을 내비친 뒤로는 드라마로 넘어가는지
- [ ] 개그 → 취재·NSFW: 재현이 시작되면 동작이 잘게 쪼개지고 문단마다 감각이 두 개 이상 나오는지
- [ ] 드라마·NSFW → 일상: 다음 장면이 갑자기 깔깔대지 않고 어색한 여운에서 시작하는지
- [ ] 다리 문단이 매번 같은 문장(예: 같은 소리, 같은 행동)으로 나오지 않는지. 반복되면 알려 주세요
