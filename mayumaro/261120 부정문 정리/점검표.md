# 261120 부정·제한 문구 점검

기준: 아주 크리티컬하지 않고, 같은 뜻의 제안형(~한다)이 이미 있으면 부정형(~하지 않는다)은 지운다.
범위: 라이브 메인 프롬프트(11/20 11:30 기준, 13,946자), 리마인더, [분량]. 그 밖의 세계관 문서는 이번에 손대지 않았다.

결과: 메인 13,946자 → 13,289자 (약 6,640 → 6,310토큰 추정). 숨김판 약 6,450토큰.

## 판단 원칙
- **형식 규칙의 부정은 남긴다.** 대사 두 줄 쌍, 컴포넌트 태그, 큰따옴표·줄바꿈 금지처럼 기계가 읽는 형식은 문체 창의성과 상관이 적고, 어기면 화면이 깨진다.
- **문체·서술·말투의 부정은 지운다.** 창의성을 깎는 건 이쪽이다. 같은 뜻의 제안형이 이미 있으면 부정 부분만 지우고, 없으면 제안형으로 바꾼다.
- **같은 금지가 메인과 리마인더에 둘 다 있으면 한 곳만 남긴다.** 매 턴 맨 끝에 붙는 리마인더 쪽을 남기는 걸 기본으로 했다.
- **이야기 구조·동의·정보 차단은 남긴다.** 키스는 연인 뒤, 거절하면 물러남, {{user}}의 대사를 대신 쓰지 않음, 속마음을 모름, 최종화 단계, 과거사 공개 시점.
- **'이유' 섹션은 손대지 않았다.** 금지 규칙이 아니라 "이렇게 안 되면 이런 일이 생긴다"는 설명이고, 11/13 동결판의 느낌을 만드는 부분이라서다.

## 부정문과 별개로 발견한 것 (11/20 11:42 사용자 결정으로 반영)
1. **분량이 두 군데에서 다르다.** 메인 [문체] 분량은 "한국어 본문 2,500자 이상(일본어 줄·컴포넌트 제외)", [분량]은 "응답 전체 2,500–3,000자(일본어 줄·태그 포함)". 서로 다른 기준이라 모델이 헷갈린다. 하나만 남기는 걸 권한다.
2. **혼잣말 예시가 바로 앞 규칙과 어긋난다.** "사투리 단어는 한 대사에 하나까지"인데 예시 "(아이고 마, 우짜노 이거… 내 진짜 미치겠데이…)"에는 셋 이상 들어 있다. 모델은 규칙보다 예시를 따른다.
3. **말 놓기 줄의 두 줄 말투가 다르다.** "{{user}}에게 タメ口로 말함(한국어 줄도 사투리 반말)" → 일본어는 표준어 반말인데 한국어만 사투리가 된다. "칸사이벤 タメ口"로 하면 맞는다.
4. **[마시로의 콘티 노트]가 세계관 문서 목록에 없다.** [진행]의 "수가 막히면 로어북 [마시로의 콘티 노트]에서 꺼내 변주한다"가 가리키는 문서다. 아직 안 만들었거나 다른 곳에 있다면 확인.

### 반영 (사용자 결정)
1. 분량은 [분량]을 따른다 → 메인 [문체] 분량 줄을 `- 분량: world doc [분량]을 따른다.`로 교체.
2. 혼잣말 예시 → `(진짜 우짜노…)` (사투리 표시 하나).
