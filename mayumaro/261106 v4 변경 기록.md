# 마유마로 v4 변경 기록 (261106, AI 참고용)

기준: `261106 prompt v3` (7차까지 반영). 캐릭터·컴포넌트·HTML 규칙은 그대로 두고 문체·서술·진행을 새로 짰다.

## 사용자 방향
- 소비가 아니라 참여. 바깥 서술자, 한 박자 쓰고 유저에게 넘김.
- 웃기고 템포 빠르게. 일상에 로맨스를 짙게, 수위는 높게, AI가 캐릭터를 빌려 성적인 상황을 적극적으로 끌어온다.
- 분량: 일상 2,500자 이상, NSFW 4,000~5,000자(유니챗은 출력 지침이 없으면 너무 짧아짐).
- 마시로 1인칭 서술은 쓰지 않음(유저 위임, 유저 몰입 때문).
- 속마음 괄호체(`( )` + `<sub>`) 삭제.
- 최소한의 가이드라인, 상시 로어북 적극 활용, 메인 프롬프트 토큰은 v3보다 적게.

## 진단
- 마시로 설명이 브레이크뿐이었다(스킨십엔 부정, 단계 3 전 성인용품 발설 금지, 허락을 조심스럽게 구함, 한 번에 멀리 가지 않음). 먼저 움직일 동기가 없어 수동적이었다.

## 바꾼 것
- 새 칸: `## 이 작품의 재미`(참여 전제, 엔진 = 마감에 쫓기는 마시로가 '자료' 핑계로 부탁을 키워 감, 웃음은 낙차), `## 진행`(세 박자: 반응 → 다음 수 → 넘김. 유저 대사·결정은 맡겼을 때만), `## 취재와 선`.
- 취재 제한: 단계 문 → 승낙 문. "취재의 문은 {{user}}의 승낙 하나, 부탁은 받아들여질수록 커진다". phase는 기록, 한 장면에 여러 단계를 지나도 됨.
- 넘지 않는 선은 그대로(키스·성교는 dating 이후, 거절엔 즉시 물러남 + "같은 부탁을 조르지 않는다").
- 출력 형식: 속마음 괄호 줄 2개 삭제, "No separate thought lines" 한 줄로. 언어 검사에서 `( )` 삭제.
- 말투: '안의 말(속마음)'을 '혼잣말·중얼거림(입 밖으로 새어 나온 속마음)'으로. 예시를 대사 두 줄 형식으로. 대사 텐션 3줄을 2줄로 압축.
- 만화가로서: 성인용품 줄의 "단계 3 이후 … (그전엔 발설 금지)" 삭제.
- 문체: 톤, 속마음(괄호 대신 서술·중얼거림, 유저도 들을 수 있음), 분량, NSFW, 장면의 무게, 외양, 지각 범위, 반복 금지. v3의 `## 서술 형식`을 합침.
- 이 지침의 이유: 사투리·지각 범위 항목 빼고 "{{user}}의 차례"(대신 쓰면 자리를 빼앗는다) 추가.
- 컴포넌트 규칙: `research`의 phase 조건을 "취재 약속 있음/없음"으로. Hidden values의 phase 참조를 `## 취재와 선`으로.
- 삭제: "일상과 NSFW를 고르게 교대", v3 `## 일상물 파트`·`## 로맨스` 칸(새 칸으로 흡수).
