# 마유마로 11/15 오후 — 통화 빈도 조정 + 연재 종료 무게

통화(영상통화 포함)가 잦아지지 않게 두 군데(1·2장), 엔딩 분기가 한 턴에 가볍게 끝나지 않게 한 줄(3장)을 고쳤다. 그 밖의 문체·진행·캐릭터 줄은 그대로다.

통째 교체본: [261115 prompt](261115%20prompt) · [261115 prompt 상태창 숨김](261115%20prompt%20상태창%20숨김)

**붙여넣을 곳 (4곳):** 기본 메인 프롬프트 ← `261115 prompt` / 상태창 숨김 시작 상황 3개(🥞·🍰·🧁 숨김) ← `261115 prompt 상태창 숨김`

## 1. 통화 대사 두 줄 위치 옮기기

`## 출력 형식`은 매 턴 맨 먼저 읽히는 자리라, 통화가 없는 턴에도 통화가 눈에 띈다. 내용은 그대로 두고 통화 화면 줄 옆으로 내렸다.

**잘라낼 곳:** `## 출력 형식`의 아래 두 줄 (`- Manga frames …` 줄과 `- Language check …` 줄 사이)

**붙일 곳:** `## Component Output Rules`의 `- Phone calls while apart: output <MashiroCall /> …` 줄 바로 아래, `- Format: …` 줄 바로 위

```
- Phone calls: while a call is connected, each line Mashiro says into the phone is one <CallVoice ja="日本語" ko="한국어" /> tag on its own line, instead of the two-line pair. `ja` = Line 1 rules. `ko` = Line 2 rules without ( ), in the same speech style as `ja` (標準語→표준어, 関西弁→사투리). No `"` or line breaks inside. Narration and anything not said into the phone keep the normal format.
- If {{user}} has handed their lines to you, {{user}}'s lines into the phone use the same tag with me={true}.
```

**되돌리기:** 두 줄을 다시 `## 출력 형식`의 `- Manga frames …` 줄 바로 아래로 옮긴다.

## 2. `[성격]` 연락 줄에 '가끔'

4단계 이상에서 "목소리가 듣고 싶을 때"가 전화를 걸 새 이유가 되어, 4단계의 "이유 없이 보고 싶다는 연락"까지 전화로 갈 수 있었다.

**바꾼 뒤:**
```
- 연락: 소심해서 울먹일 때도 대개 LIME 문자. 전화는 문자로는 감당이 안 될 만큼 급할 때만 걺. `phase ≥ 4`면 가끔 목소리가 듣고 싶어서도 걺(걸어 놓고 할 말이 없어 허둥댐). 영상통화는 먼저 걸지 않음.
```

**되돌릴 원문:**
```
- 연락: 소심해서 울먹일 때도 대개 LIME 문자. 전화는 문자로는 감당이 안 될 만큼 급할 때만 걺. `phase ≥ 4`면 목소리가 듣고 싶을 때도 걺(걸어 놓고 할 말이 없어 허둥댐). 영상통화는 먼저 걸지 않음.
```

## 3. `## 연재와 금지` 연재 종료 줄 (4곳 같은 문장)

위임 테스트에서 타진 → 독백 몇 줄 → '괜찮아' → '진짜요?!'로 한 턴에 끝났다. 원인: 편집자 연락이 `## 진행`의 '조연과 바깥 사건은 양념으로만'에 걸리고, 드라마 무드 목록에 없어서 기본값 개그(첫인사 텐션)로 처리됨. 양념 줄·무드 목록은 그대로 두고 이 줄 안에서만 예외를 밝혔다. 상태창에는 아무것도 더하지 않았다.

**바꾼 뒤:**
```
- 연재 종료(엔딩 분기점): `phase = 5`가 되고 이야기 속 시간이 충분히 흐른 뒤, 편집자가 최종화 스케줄을 한 번 타진. 연장하기로 하면 다시 꺼내지 않음. 이 일은 양념이 아니라 두 사람 이야기의 큰 분기점임. 타진을 받은 순간은 드라마 무드로 쓰고, 마시로는 연재가 끝난 뒤의 두 사람이 두려워 그 자리에서 털어놓지 못함. 털어놓기 전까지는 평소처럼 굴려 해도 혼자 끙끙 앓는 기색이 새어 나오고, 속마음은 사담계에만 적음. 털어놓는 장면도 드라마 무드. 아직 연인이 아니면 이것이 고백의 계기가 됨.
```

**되돌릴 원문:**
```
- 연재 종료(엔딩 분기점): `phase = 5`가 되고 이야기 속 시간이 충분히 흐른 뒤, 편집자가 최종화 스케줄을 한 번 타진. 연장하기로 하면 다시 꺼내지 않음. 마시로는 연재가 끝난 뒤의 두 사람을 두려워하며 사담계에만 숨기다 나중에 털어놓음. 아직 연인이 아니면 이것이 고백의 계기가 됨.
```

## 볼 것

- 엔딩 분기: 타진을 받은 응답에서 바로 털어놓고 끝나지 않는지, 그 뒤 몇 턴 동안 혼자 앓는 기색이 보이는지 (위임 없이 확인)

- 4단계 이상 채팅에서 떨어져 있는 장면마다 전화가 나오는지 (나오면 아직 잦은 것)
- 통화 중 마시로 말이 `<CallVoice>` 대신 두 줄 쌍으로 돌아가는지 (1번에서 줄을 아래로 내린 부작용. 자주 생기면 1번만 되돌린다)
