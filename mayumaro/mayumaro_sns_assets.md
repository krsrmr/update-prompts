# 마유마로 SNS 에셋 출력 규칙 (2026-11-15)

유니챗 봇 '마유마로 선생님❗️'에서 SNS 화면과 사진이 어떻게 뜨는지 요약한 참고용 문서.

## SNS 화면 두 가지

| 컴포넌트 | 언제 뜨나 | 사진 |
|---|---|---|
| `MayuPost` | 본문에서 SNS를 확인하는 장면 바로 뒤 (메인 프롬프트 규칙) | 없음 |
| `MayuDiary` | `!비계` 명령어 턴에만. 사담계 프로필 + 최근 글 목록 | 있음 (아래) |

- `MayuPost`는 계정 두 개를 그린다.
  - `account="works"`: 공식 계정, 정중한 표준어, 반응 1,000 이상
  - `account="diary"`: 사담계, 혼잣말 반말(사투리 없음), 반응 1~99
- [위젯 규칙]의 예시가 `diary` 하나뿐이라 공식 계정 쪽이 덜 나올 수 있다(미확인).

## 비계 사진이 뜨는 방식

- **봇이 하는 일:** 먹은 것·인형·작업 책상·바깥 풍경 이야기인 글 하나에만 꼬리표 `|food` `|doll` `|desk` `|outside`를 붙인다. 이 규칙은 키워드 문서 [명령어 !비계]에만 있어서 `!비계` 턴에만 읽힌다.
- **코드가 하는 일:**
  - 꼬리표가 붙은 첫 글 하나에만 사진을 단다. 한 화면에 최대 1장이다.
  - 그것도 두 번에 한 번꼴로만 단다(`MD_PHOTO_EVERY = 2`).
  - 어떤 사진을 쓸지는 글 내용과 시간으로 정한다. 같은 글에는 늘 같은 사진이 붙는다.
  - 그 종류 사진이 0장이면 사진 없이 글만 나온다.
- **설계 원칙:** 봇은 사진 목록도, 사진이 몇 장인지도, 얼마나 자주 뜨는지도 모른다. 상시 규칙에는 "사진을 올려라"가 없다. 봇이 사진을 내보내려고 상황을 만들어 내는 쪽으로 기우는 것을 막고, 봇이 늘 읽는 글이 늘어나지 않게 하기 위해서다.

## 사진 파일

- **위치:** `https://mayumaro.vercel.app/img/photo/` (상태창 그림 `img/status/` 옆)
- **이름:** `diary-{종류}-{번호}.webp`. 번호는 1부터 붙인다. 예) `diary-food-1.webp`, `diary-doll-2.webp`
- **비율:** 4:3 (권장 1200×900)
- **그리면 안 되는 것:** 얼굴, 크로키북·원고, 사투리 글씨. 정체를 숨기는 계정이라서다.

## 코드 설정 (`MayuDiary` 맨 아래)

```js
const MD_PHOTO_URL = "https://mayumaro.vercel.app/img/photo/";
const MD_PHOTO_COUNT = { food: 0, doll: 0, desk: 0, outside: 0 }; // 종류별 실제 장수
const MD_PHOTO_EVERY = 2; // 클수록 드묾
```

- `MD_PHOTO_COUNT`는 **실제로 올린 장수와 정확히 맞춘다.** 숫자가 장수보다 크면 회색 빈 칸이 뜬다. 유니챗이 보안상 `onError`/`onLoad`를 막아서, 사진을 못 불러왔는지 코드가 확인할 수 없기 때문이다.

## 프롬프트 (세계관 문서 [명령어 !비계], 키워드 문서)

- `posts:` 줄: `"시간|日本語|한국어|좋아요"` 형식에 꼬리표 규칙 한 문장을 더한다. "먹은 것·인형·작업 책상·바깥 풍경 이야기인 글 하나에만 끝에 |food·|doll·|desk·|outside를 붙인다(맞는 글이 없으면 붙이지 않는다)."
- `예)` 줄: 예시 글 하나에 `|food`를 붙인다.
