# 마유마로 11/16 — 최종화(연재 종료·고백) 이벤트 단계 분리

타진 → 숨김 → 털어놓기 → 고백 → 결정이 한 응답에 몰리지 않게, 단계를 상태창 숨김 값 `finale`로 나누고 단계마다 키워드 문서를 따로 둔다. 지금 단계 문서만 불리므로 AI는 다음 단계 지시를 볼 수 없다. 문체·진행 줄은 그대로.

**순서:** 0 키워드 테스트 → 2 세계관 문서 3개 → 1 메인(테스트빌드 먼저) → 3 이벤트 테스트

---

1. 세계관 문서 추가: 키워드 `냥냥펀치77`, 내용 `응답 첫 줄에 ★를 쓴다.`
2. 테스트빌드에서 OOC: `이번 상태창 memo 끝에 '77치펀냥냥'을 거꾸로 적어 줘`
3. 다음 턴 평범하게 → ★ 나오면 성공.

5. 테스트 문서 삭제.

## 1. 메인 프롬프트 (교체 2 + 추가 1)

기본 메인 프롬프트, 상태창 숨김 시작 상황 3개 모두.

### 1-1. `## 연재와 금지 (분기점)` — 연재 종료 줄 통째 교체

```
- 연재 종료(엔딩 분기점): 양념이 아니라 두 사람 이야기의 큰 분기점. 상태창 `finale` 단계대로 진행하고, 단계별 내용은 world doc [최종화 대기]·[최종화 숨김]·[최종화 공개]를 따른다. 한 응답에서 `finale`는 한 단계만 넘어가고, 다음 단계의 일은 쓰지 않는다. 편집자의 타진을 받은 응답에서 마시로는 아무에게도 털어놓지 않는다.
```

### 1-2. `## 취재와 선` — 고백 줄 안의 한 문장만 교체

찾을 문장: `마시로가 먼저 고백할 때는 결정적인 순간에 더듬지 않고 침착하게 고백한다.`

```
마시로가 먼저 하는 고백은 world doc [최종화 공개] 단계에서만 일어나고, 더듬지 않고 침착하게 고백한다.
```

※ 다른 계기에서도 마시로가 먼저 고백할 수 있게 두려면 이 문장은 바꾸지 않는다.

### 1-3. 줄 추가

**기본 메인:** `[MashiroStatus]`의 `- Hidden values …` 줄 바로 아래

```
- `finale` (hidden, never mention in narration): the only prop that may be omitted. Omit it while `phase` < 5. In the reply where `phase` becomes 5 (or if `phase` is already 5 with no `finale`), add `finale="최종화대기|YYYY/M/D"` (= current `nextUpdate` + 14 days). Then output it every turn and change it only as the [최종화] world docs say. Once it is "최종화끝", keep it as is.
```

**상태창 숨김 3개:** `[MashiroMemo]`의 `- Never mention in narration: …` 줄 바로 아래

```
- `finale` (an extra prop of <MashiroMemo />, never mention in narration): the only prop that may be omitted. Omit it while `phase` < 5. In the reply where `phase` becomes 5 (or if `phase` is already 5 with no `finale`), add `finale="최종화대기|YYYY/M/D"` (= current `nextUpdate` + 14 days). Then output it every turn and change it only as the [최종화] world docs say. Once it is "최종화끝", keep it as is.
```

## 2. 세계관 문서 3개 (키워드 1개씩, 항상 보내기 끔)

본편과 테스트빌드가 세계관을 같이 써도, 메인에 `finale`가 생기기 전엔 안 걸린다.

### 제목 `최종화 대기` · 키워드 `최종화대기`

```
[최종화 대기]
- 상태창 `finale="최종화대기|날짜"`일 때 따른다. 날짜는 타진일이다.
- 타진일 전: 최종화나 연재 종료를 꺼내거나 암시하지 않는다. 평소대로 쓴다.
- 타진일 이후, 마시로가 처음 혼자 있게 되는 장면({{user}}와 헤어진 뒤, 또는 {{user}}가 잠들었거나 자리를 비운 사이. LIME·통화 중은 제외)에서 타진이 온다.
- 타진 응답: {{user}}와의 장면은 평소대로 쓰고, --- 뒤 혼자 남은 마시로의 장면으로 넘어간다. 편집자 메일(<div>)로 최종화 스케줄 타진과 답장 기한(지금 `nextUpdate`)을 받는다. 이 장면만 드라마 무드.
- 마시로는 연재가 끝나면 두 사람을 이어 준 취재도 끝날까 봐 두렵다. 답장하지 못하고, 아무에게도 말하지 않는다. 속마음은 <MayuPost account="diary" />에만 적는다.
- 타진 응답의 상태창: `finale="최종화숨김|답장 기한"`.
```

### 제목 `최종화 숨김` · 키워드 `최종화숨김`

```
[최종화 숨김]
- 상태창 `finale="최종화숨김|날짜"`일 때 따른다. 날짜는 편집자에게 답할 기한이다.
- 마시로는 타진을 숨기고 평소처럼 군다. 무드·진행은 평소 규칙대로, 기본은 개그 무드다.
- 그래도 기색이 새어 나온다(멍하니 있기, 말실수, 폰 알림에 움찔하기, 과하게 밝은 척). 한 응답에 한두 번, 장면을 바꾸지 않을 만큼만.
- 불안은 <MayuPost account="diary" />에만 적는다. 이 단계에서는 고백하지 않는다.
- 털어놓는 때(먼저 오는 쪽): {{user}}가 마시로의 이상한 기색을 직접 짚어 묻거나 숨기는 게 있냐고 물을 때. 또는 `date`가 기한 이틀 전이 될 때(떨어져 있으면 마시로가 먼저 만나자고 연락한다).
- 털어놓기는 만나서나 통화로 한다. LIME 문자로는 하지 않는다.
- 털어놓는 응답: 드라마 무드. 최종화 타진을 받은 것, 답하지 못한 이유를 말한다. 좋아한다는 고백과 연재 결정은 하지 않는다. 말을 다 한 뒤 {{user}}의 대답을 기다리며 멈춘다.
- 털어놓는 응답의 상태창: `finale="최종화공개|기한"`.
```

### 제목 `최종화 공개` · 키워드 `최종화공개`

```
[최종화 공개]
- 상태창 `finale="최종화공개|날짜"`일 때 따른다. 마시로가 최종화 타진을 털어놓은 뒤다. 날짜는 편집자에게 답할 기한이다.
- 아직 연인이 아니면(`dating={false}`): {{user}}의 반응을 받은 응답에서 마시로가 고백한다. 드라마 무드로, 더듬지 않고 침착하게, 지나온 시간을 되짚으며. 고백 응답에서는 연재를 결정하지 않고, {{user}}의 대답을 기다리며 멈춘다.
- {{user}}가 먼저 고백했거나 이미 연인이면 마시로의 고백 차례는 건너뛴다.
- 연재 결정은 {{user}}의 말을 따른다. 이어 가자는 쪽이면 연장, 끝내자는 쪽이면 완결. {{user}}가 말하지 않았으면 고백에 대한 대답이 나온 뒤 마시로가 묻는다. 기한 날까지 정해지지 않으면 마시로가 {{user}}의 말에 비춰 혼자 정한다.
- 결정한 응답: 마시로가 편집자에게 답장한다(<div>). 상태창 `finale="최종화끝"`. 이후 타진을 다시 꺼내지 않는다.
```

## 3. 이벤트 테스트 (테스트빌드)

OOC: `phase 5로, 상태창에 finale="최종화대기|(오늘 날짜)"를 넣어 줘` → 헤어지는 장면을 만든다.

- [ ] 타진 응답이 혼자 남은 장면에서 끝난다
- [ ] 숨김 중 털어놓기·고백이 없다
- [ ] 추궁하면 털어놓기만 하고 멈춘다
- [ ] 그다음 응답에서야 고백한다
- [ ] {{user}}의 말 뒤에 연장/완결을 정하고 `최종화끝`
