# 🧁 서점 시작: "크로키북 돌려주세요" 반복 고치기 (261120 15:30)

## 증상
{{user}}가 크로키북을 안 돌려주면, 마시로가 계속 돌려달라는 말만 되풀이한다. 본편과 테스트빌드 둘 다 그렇다.

## 원인
🧁만 크로키북이 {{user}} 손에 있다. 🥞·🍰는 마시로가 크로키북을 안고 도망칠 수 있다.
- 메인 [성격] "크로키북·원고는 몸이 먼저 지킴": 크로키북을 되찾는 게 마시로의 1순위 목표가 된다.
- 메인 [진행] "어떻게 받아들여지는지는 {{user}}가 정한다", "{{user}}의 결정은 쓰지 않는다": 마시로는 크로키북을 뺏을 수 없다. 돌려달라고 내민 데서 멈춘다.
- 메인 [넘지 않는 선] "거절하면 바로 물러나 사과": 물러났다가 다시 부탁한다. 말만 바꾸니 모델은 '조르기'로 보지 않는다.
- 관계 1단계 "도망치고 매달린다": 크로키북 없이는 도망칠 수 없으니 '매달린다'만 남는다.
- 🧁 시작 상황에는 🥞의 "도망에 장렬히 실패하거나 간신히 성공한다" 같은 장면 끝이 없다. 숨김판의 "기절 직전"도 끝나지 않는 상태다.

결론: 마시로의 목표를 {{user}}만 풀 수 있는데, 장면을 끝낼 다른 길이 없다. 브레이크가 많아서가 아니라 출구가 없어서 생긴 고리다. 그래서 지울 문장이 없고, 출구 한 문장이 필요하다.

## 고칠 곳
유니챗 → 🧁 気まぐれロマンティック, 🧁 【상태창 숨김】 → 시작 상황 프롬프트 → 셋째 줄 맨 끝.

붙일 문장 (둘 다 같음, 앞에 띄어쓰기 한 칸):
```
 크로키북을 되찾든 못 되찾든 결국 요란하게 도망친다.
```

글자 수: 기본판 450 → 480, 숨김판 451 → 481 (한도 500).

크로키북을 못 되찾고 도망치면, 넷째 줄 "두 사람은 필연적 사건으로 다시 만난다"가 재회를 맡는다. 크로키북은 다시 만날 핑계가 된다.

## 확인
지금 방에는 반복된 응답이 쌓여 있어서 계속 따라 한다. 새 대화로 시험한다. 크로키북을 일부러 안 돌려주는 대사를 2~3번 친다.
