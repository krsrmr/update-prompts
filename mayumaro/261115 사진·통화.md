# 마유마로 11/15 — 사진·통화 기능

동결본(11/13)의 문체·진행 줄은 건드리지 않는다. 메인 프롬프트는 **한 줄 추가**만 한다.

| 기능 | 어떻게 뜨나 | AI가 아나 |
|---|---|---|
| 취소된 셀카 (LIME) | 전송 취소 칸 몇 번에 한 번이 '사진 전송 취소'가 되고, 누르면 셀카가 열린다 | 모름 |
| 비계 사진 | `!비계` 글 하나에 사진. 한 화면 최대 1장, 비계를 두 번 열면 한 번꼴 | `!비계` 턴에만 |
| 통화 화면 | 떨어져서 통화가 연결될 때 한 번. 영상통화는 상황 그림, 없으면 '카메라 꺼짐' | 통화가 생겼을 때만 |
| 영상통화 성격 | 마시로는 영상통화를 싫어해서 먼저 걸지 않음 | 성격 한 줄 |

- 통화 NSFW는 막지도, 부추기지도 않는다(아무 말도 쓰지 않음). 지금의 취재 규칙대로 열려 있다.
- 사진이 하나도 없어도 기능은 돌아간다. 셀카·비계 사진은 장수가 0이면 안 뜨고, 영상통화는 '카메라 꺼짐'이 뜬다.

## 2. 메인 프롬프트 — 한 줄 추가 (두 버전 모두)

**위치:** `## Component Output Rules`의 `- Commands: …` 문단 바로 아래, `- Format: Strings in …` 줄 바로 위.

```
- Phone or video calls while apart: in the reply where the call connects, output <MashiroCall /> once, before the final tag. The call itself is written in the normal format. Props: world doc `[위젯 규칙]`.
```

- 상태창 있는 버전, 상태창 없는 버전 둘 다 같은 자리에 같은 줄.
- '마시로가 전화를 걸 수 있다'는 말은 일부러 쓰지 않았다. 통화가 **생겼을 때의 처리만** 적어서, 거는 이유는 기존 연락 동기(성격·단계별 연락)에 맡긴다.
- **되돌리기:** 이 한 줄만 지우면 11/13 동결본 그대로다.

## 3. 세계관 문서 [위젯 규칙] (상시)

**① 맨 위 첫 줄 교체**

원문:
```
Props and content of <MayuPost />, <LunelleEpisode />, <LimeChat />, and <MashiroStash />. When to output them follows the main prompt's Component Output Rules.
```
교체:
```
Props and content of <MayuPost />, <LunelleEpisode />, <LimeChat />, <MashiroStash />, and <MashiroCall />. When to output them follows the main prompt's Component Output Rules.
```

**② 문서 맨 끝에 추가**
```
[MashiroCall]
- Only in the reply where the call connects. Never output it again while the same call continues.
- `video={true}` only for a video call. Otherwise `{false}`.
- `doing`: what Mashiro was doing when the call connected, short Korean (예: 침대에서 뒹굴던 중, 원고 작업 중, 학교 복도에서). `clock`: the time it connected. `name`: his LIME name (default "真白").
- e.g.
<MashiroCall video={false} doing="원고 작업 중" clock="23:41" />
```

**되돌리기:** ①을 원문으로, ②를 지운다.

## 5. 세계관 문서 [명령어 !비계] (키워드 `!비계`)

**`posts:`로 시작하는 줄 교체**

원문:
```
posts: "시간|日本語|한국어|좋아요". 최신 글이 위. 시간은 "3分", "2時間", "昨日", "11月3日"처럼. 좋아요 1~99. following, followers는 숫자(followers 10~30 안팎). clock은 지금 시각.
```
교체:
```
posts: "시간|日本語|한국어|좋아요". 최신 글이 위. 시간은 "3分", "2時間", "昨日", "11月3日"처럼. 좋아요 1~99. 먹은 것·인형·작업 책상·바깥 풍경 이야기인 글 하나에만 끝에 |food·|doll·|desk·|outside를 붙인다(맞는 글이 없으면 붙이지 않는다). following, followers는 숫자(followers 10~30 안팎). clock은 지금 시각.
```

**예시 줄 교체**

원문:
```
예) <MayuDiary clock="23:41" following={38} followers={12} posts={["3分|あの人のこと考えてたら、ペン入れ1ページも進まなかった|그분 생각하다가 펜선 한 페이지도 못 나갔다|2", "昨日|コンビニの新作プリン、ふたつ買っちゃった|편의점 신상 푸딩 두 개 사버렸다|7"]} />
```
교체:
```
예) <MayuDiary clock="23:41" following={38} followers={12} posts={["3分|あの人のこと考えてたら、ペン入れ1ページも進まなかった|그분 생각하다가 펜선 한 페이지도 못 나갔다|2", "昨日|コンビニの新作プリン、ふたつ買っちゃった|편의점 신상 푸딩 두 개 사버렸다|7|food"]} />
```

AI가 매번 하나씩 붙여도, 코드가 한 화면 1장 + 두 번에 한 번꼴로만 띄운다.

## 6. 사진 올리기

상태창 그림과 같은 사이트(`mayumaro.vercel.app`)의 **`img/photo/`** 폴더에 올린다. 상태창 그림이 있는 `img/status/` 옆이다.

| 쓰는 곳 | 파일 이름 | 비율 (권장 크기) | 올린 뒤 할 일 |
|---|---|---|---|
| 취소된 셀카 | `selfie-1.webp`, `selfie-2.webp` … | 3:4 (900×1200) | `LimeChat` 코드 맨 아래 `LC_SELFIE_COUNT = 0`을 올린 장수로 |
| 비계 사진 | `diary-food-1.webp`, `diary-doll-1.webp`, `diary-desk-1.webp`, `diary-outside-1.webp` … | 4:3 (1200×900) | `MayuDiary` 코드 맨 아래 `MD_PHOTO_COUNT`의 종류별 숫자를 장수로 |
| 영상통화 | `vc-상황.webp` (아래 표) | 9:16 (1080×1920) | 없음. 올리면 바로 뜬다 |

- 장수 숫자는 **실제로 올린 수와 꼭 맞춘다.** 숫자보다 사진이 적으면 빈 칸(회색)이 뜬다. 유니챗은 사진을 못 불러왔는지 알아내는 기능을 보안상 막아 둬서, 코드가 대신 확인할 수 없다.
- 빈도 조절: 셀카는 `LC_SELFIE_EVERY`(기본 4: 전송 취소 4번에 1번꼴), 비계는 `MD_PHOTO_EVERY`(기본 2). 숫자가 클수록 드물다.
- 셀카는 마시로가 보냈다가 부끄러워서 지운 사진이다. 얼굴이 나와도 된다. 비계 사진은 정체를 숨기는 계정이라 얼굴·크로키북·사투리 글씨가 나오지 않게 한다.

## 7. 붙여넣은 뒤 확인할 것

- [ ] **빈도 비교(가장 중요):** 바꾸기 전과 같은 상황을 몇 번씩 돌려서, 마시로가 먼저 연락하는 횟수와 그중 통화 비율을 센다. 추천 상황: 밤으로 건너뛰며 헤어진 날 / 3단계에서 원고가 막힌 날 / 취재 끝나고 헤어진 날. 통화가 문자를 대부분 대신하거나 연락 자체가 잦아지면 2번의 한 줄을 지운다.
- [ ] 마시로가 먼저 영상통화를 걸지 않는지. {{user}}가 영상통화를 걸면 `video={true}`로 뜨는지.
- [ ] 통화 화면이 연결된 응답에서 한 번만 뜨고, 다음 응답부터는 평소 형식으로 대화가 이어지는지.
- [ ] `!비계`에서 사진이 매번이 아니라 가끔 뜨는지(사진을 올린 뒤).
- [ ] LIME 전송 취소 중 가끔 '사진 전송 취소'가 뜨고, 누르면 셀카가 열리고 다시 누르면 닫히는지(사진을 올린 뒤).
